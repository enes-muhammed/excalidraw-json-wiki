# `containerId`

Text elementini bir text container'a bağlar.

``` json
"containerId": "rectangle123"
```

Bağlanabilecek container tipleri: - rectangle - stickynote - diamond -
ellipse - arrow

Bağlı değilse `null`.

Container tarafında karşılık olarak `boundElements` içinde text ID'si
bulunabilir.

Kaynak: `packages/element/src/types.ts`.
