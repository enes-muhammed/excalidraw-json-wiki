# Text element

Temel yapı:

``` json
{
  "type": "text",
  "text": "Sinir Sistemi",
  "originalText": "Sinir Sistemi",
  "fontSize": 28,
  "baseFontSize": null,
  "fontFamily": 5,
  "textAlign": "center",
  "verticalAlign": "middle",
  "containerId": null,
  "autoResize": true,
  "lineHeight": 1.25
}
```

Ek olarak ortak element alanları bulunur.

Özel alanlar: - `text` - `originalText` - `fontSize` - `baseFontSize` -
`fontFamily` - `textAlign` - `verticalAlign` - `containerId` -
`autoResize` - `lineHeight` - opsiyonel `labelPosition`

Kaynak: `packages/element/src/types.ts`.
