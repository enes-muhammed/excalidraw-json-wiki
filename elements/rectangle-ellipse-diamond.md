# Rectangle, ellipse, diamond

Bu üç temel geometrik element ortak base şemasını kullanır ve kendi
başına ek JSON alanına sahip değildir.

Tip: - `rectangle` - `ellipse` - `diamond`

Örnek:

``` json
{
  "type": "rectangle",
  "x": 100,
  "y": 100,
  "width": 300,
  "height": 150
}
```

Diğer ortak alanlar yine zorunludur.

Kaynak: `packages/element/src/types.ts`.
