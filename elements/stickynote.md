# Sticky note

Tip:

``` json
"type": "stickynote"
```

Ek alan:

``` json
"baseHeight": 250
```

`baseHeight`, kullanıcının ayarladığı temel yüksekliği temsil eder. Note
label'ının sığması için gerçek `height` bundan büyüyebilir.

Sticky note ayrıca text binding ile çalışır.

Kaynak: `packages/element/src/types.ts`,
`packages/common/src/constants.ts`.
