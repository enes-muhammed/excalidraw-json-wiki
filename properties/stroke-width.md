# `strokeWidth`

Çizgi kalınlığıdır.

Normal elementler için kaynak sabitleri:

-   `thin` → `1`
-   `medium` → `2`
-   `bold` → `4`
-   `extraBold` → `8` (kaynakta kullanılmıyor / gelecekte
    kullanılabilir)

FreeDraw için ayrı ölçek:

-   `thin` → `0.5`
-   `medium` → `1`
-   `bold` → `2`
-   `extraBold` → `4`

AI üretiminde normal şekiller için doğrudan 1, 2 veya 4 güvenli temel
değerlerdir.

Kaynak: `packages/common/src/constants.ts`.
