angle

Elementin dönüş açısıdır.

"angle": 0


Tip: number / radyan.

Düz bir eğitim diyagramı için çoğu elementte 0 kullanılabilir.

angle, derece değil, radyan cinsinden saklanır.

Örnekler:

Dönüş	Radyan
0°	0
45°	0.785398...
90°	1.570796...
180°	3.141592...
270°	4.712389...

Örneğin, 90°'lik bir dönüş yaklaşık olarak şu şekilde gösterilebilir:

{
  "angle": 1.5707963267948966
}


Kaynak: packages/element/src/types.ts.
