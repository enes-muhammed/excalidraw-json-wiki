# `type`

Elementin türünü belirtir.

Güncel element union'ında: - `selection` - `rectangle` - `stickynote` -
`diamond` - `ellipse` - `embeddable` - `iframe` - `image` - `frame` -
`magicframe` - `text` - `line` - `arrow` - `freedraw`

Araç türleri (`lasso`, `hand`, `laser`, `autoshape`, `bucketfill` gibi)
element tipi değildir.

Kaynak: `packages/element/src/types.ts`, `ExcalidrawElement`; araçlar
için `packages/excalidraw/types.ts`.
