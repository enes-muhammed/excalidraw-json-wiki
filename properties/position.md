# `x` ve `y`

Elementin sahne koordinatlarındaki başlangıç konumudur.

``` json
{
  "x": 100,
  "y": 200
}
```

Tip: `number`

Koordinatlar Excalidraw sahne uzayındadır. AI tarafından üretilen bir
çizimde bütün elementleri aynı koordinat sisteminde yerleştirmek
gerekir.

Kaynak: `packages/element/src/types.ts`.
