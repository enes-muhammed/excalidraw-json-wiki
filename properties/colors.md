# `strokeColor` ve `backgroundColor`

## `strokeColor`

Çizgi/randövu rengini belirtir.

``` json
"strokeColor": "#1e1e1e"
```

## `backgroundColor`

Elementin dolgu rengidir.

``` json
"backgroundColor": "#a5d8ff"
```

Şeffaflık için kaynak kodda kullanılan değer `"transparent"`tır.

Renk paleti için `packages/common/src/colors.ts` incelenmelidir.

Kaynak: `packages/element/src/types.ts`,
`packages/common/src/colors.ts`.
