# Version ve MIME sabitleri

## Excalidraw version

``` text
VERSIONS.excalidraw = 2
VERSIONS.excalidrawLibrary = 2
```

## MIME

Normal `.excalidraw`: `application/vnd.excalidraw+json`

Clipboard: `application/vnd.excalidraw.clipboard+json`

Library: `application/vnd.excalidrawlib+json`

Library ID listesi: `application/vnd.excalidrawlib.ids+json`

Kaynak: `packages/common/src/constants.ts`.
