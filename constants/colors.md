# Renkler

Element renk alanları string olarak tutulur.

Örnek:

``` json
"strokeColor": "#1e1e1e",
"backgroundColor": "#a5d8ff"
```

Şeffaf arka plan:

``` json
"backgroundColor": "transparent"
```

Tam renk paleti kaynakta `packages/common/src/colors.ts` içindeki
`COLOR_PALETTE` ile tanımlanır.

Wiki'nin ilerleyen sürümünde palette değerleri ayrı bir tablo halinde
çıkarılacaktır.
